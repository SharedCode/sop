Kill the Agent Mid-Task. Watch It Resume.

Each reasoning step below is written to the B-Tree as a durable, atomic checkpoint the instant it happens. Kill the agent process and the committed steps stay put, no Redis, no separate checkpoint store. A successor agent reads the last checkpoint straight out of the B-Tree and keeps going.
